# Data Privacy Audit – University of Delhi Student Portal

## Objective
To conduct a basic data privacy audit of the University of Delhi
Student Portal and identify potential privacy risks and recommend
appropriate security controls.

## Website Audited
University of Delhi Student Portal:
https://slc.uod.ac.in/

## Scope
The audit focused on:
- Personal information
- Academic information
- Authentication
- Password management
- Session security
- Visibility of student information
- Protection of uploaded documents

## Methodology
1. Accessed the student portal.
2. Logged in using an authorized student account.
3. Identified categories of personal information displayed.
4. Reviewed available privacy and security controls.
5. Checked logout and session behavior.
6. Identified potential privacy risks.
7. Prepared recommendations.

## Findings

| Finding | Risk Level | Recommendation |
|---|---|---|
| Personal information is available after login | Medium | Minimize displayed information |
| Academic information is accessible | High | Enforce strict access control |
| Password authentication is used | Medium | Consider stronger authentication |
| Uploaded documents may contain sensitive data | High | Restrict and encrypt document access |

## Recommendations
- Use strong authentication.
- Apply role-based access control.
- Minimize collection and display of personal data.
- Encrypt sensitive information.
- Implement secure session management.
- Provide clear privacy policies.
- Maintain security logs and monitoring.

## Conclusion
The audit identified several areas where privacy and security
controls should be continuously reviewed. Appropriate access
control, data minimization, encryption, authentication and
session-management practices can reduce privacy risks.
